## Objective

## Problems and Complexity

| No. | Problem | Approach | Time Complexity | Auxiliary Space |
|---|---|---|---|---|
| 1 | Diagonal Difference | Calculate both diagonal sums | O(N) | O(1) |
| 2 | Dynamic Array | Use sequences and XOR-based indexing | Expected O(N + Q) | O(N + Q) |
| 3 | Time Conversion | Convert 12-hour time to 24-hour format | O(1) | O(1) |
| 4 | Compare the Triplets | Compare scores and count points | O(1) | O(1) |
| 5 | Sparse Arrays | Count string frequencies with a dictionary | Expected O(N + Q) | O(N) |
